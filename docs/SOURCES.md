## 后续收录流程

1. 保存候选来源链接、版本、车型范围；取得权利说明或明确许可证及上游证据。
2. 分别核查题干、解析、图片，不将代码许可证当作所有题库素材的许可证。
3. 对照最新官方依据校验答案、申领情形及车型适用性，记录条号、核验人员和日期。
4. 在本地导入已授权记录；未核验记录保持 pending，争议记录标 disputed。
5. 验证后构建，检查覆盖统计及公开数据；实际发布量以 published 为准。

原始候选题目不得直接提交公开仓库。需要调查时只保存链接与问题描述。
新法规影响现有答案时先撤回对应题目，再核验和修订，不静默保留旧答案。
