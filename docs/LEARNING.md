# 学习、练习与错题复习

## 本地打开

Windows PowerShell 在项目目录执行：

```powershell
.\start-learning.ps1
```

脚本构建本地题库，再启动仅监听本机的预览服务，默认打开地址为 `http://127.0.0.1:8765`。
如端口占用，使用 `.\start-learning.ps1 -Port 8770`。终端保持运行，结束时按 Ctrl+C。
需要 Python 3.11+ 与 Node.js 20+。脚本优先 PATH 中可用 Python，并兼容本机已发现的 Quark Python 运行时。
若系统限制执行脚本，可在已配置好 Python 的终端直接执行下面两条命令：

```sh
python build_learning.py --source local
node serve.mjs
```

首次需要 `local-bank/questions.json`，由前面的 merge_bank.py 合并步骤生成。
不要直接双击 HTML，浏览器对本地 JSON 读取可能有限制。

## 内容完整性

构建时排除缺题干、缺选项、无效答案、缺解析、缺图片和答案争议题；不会删除原始记录。
本次本地数据3765题，排除192题（55题缺图、137题缺解析），可用于练习3573题。
练习和知识卡只使用过滤后的数据，图片在浏览器中加载失败也会被暂时移出当次题池。
补齐源数据后重新构建即可重新纳入。原始调查报告与被排除ID分别保留。

新增资料没有明确车型映射，默认显示“导入题 · 车型待核验”。选择C1等具体车型时，只展示有该适用标记的题。
完整性检查不等于答案、时效性、版权或官方真题身份已经核验；界面保留来源标记。

## 学习流程

1. 在“今日学习”选择科目、适用范围。无数据的车型明确显示为空。
2. “考点学习”按章节阅读知识卡；理解后进入练习。读卡次数不计作答正确率。
3. “题目练习”每轮最多20题，优先未练题；支持判断、单选、多选，提交后展示答案与原解析。
4. 答错或选择“不确定”会进入错题本，安排10分钟后的第一次复习。
5. “错题复习”按最早到期时间排队，提前重练不能代替到期复习；再次答错重置周期。
6. “学习计划”按目标日期、每日时间、进度和到期题量调整任务，时间不够时提示积压。

## 间隔规则与学习依据

默认复习间隔为10分钟、1天、3天、7天、14天、30天。每次到期并答对后，从本次作答时间计算下一间隔。
完成全部6次到期复习才标为完成；普通练习中答对或未到期的提前重练不会提前升级。
答错、不确定会重新从10分钟开始；完成后再次答错也会重新激活。
算法位于 web/core.mjs，DEFAULT_INTERVALS 以分钟为单位，可配置；recordAnswer 支持传入自定义间隔。
当前界面使用统一默认间隔，根据每个人的答题表现动态重置或推进，不声称已拟合个人遗忘曲线。

间隔复习受遗忘与主动提取研究启发。这组具体数字是可解释的产品默认值，不是对艾宾浩斯研究的精确复刻。
参考：[Cepeda等（2008），复习间隔与目标记忆时长](https://escholarship.org/uc/item/0kp5q19x)、
[Karpicke与Bauernschmidt（2011），间隔提取练习](https://pubmed.ncbi.nlm.nih.gov/21574747/)。

## 学习计划与整个学车过程

默认30天、每天30分钟；可改目标科目、考试日期（未来一年内）、每日5–240分钟。
以每题50秒为估算基准，优先分配到期复习，剩余预算用于未练题；逾期任务保留，不自动算完成。
备考时间按30%建立框架、40%分章练习、20%错题巩固、10%考前回顾划分，实际任务随进度变化。
这些比例是产品默认分配，不是法定培训或考试标准；未把首次覆盖时间误称为完整复习所需时间。

报名、科目一、科目二训练、科目三道路训练、安全文明驾驶常识、领证都可设置目标日期并勾选完成。
实操阶段只管理目标和进度，不代替教练指导，不自动预约考试，也不推断特定车型的免考资格。

## 进度与隐私

答题统计、知识卡阅读、错题间隔、计划与里程碑保存在当前浏览器localStorage，无账号、无服务端同步。
支持JSON导出与恢复。清理浏览器数据、换浏览器或换设备前先导出备份。
改变预览端口也会改变浏览器存储空间，可通过备份迁移。
恢复时校验格式；同ID题目内容变更后，通过fingerprint使旧掌握度失效，避免沿用旧答案的复习记录。
网页关闭时不会推送提醒；再次打开或每分钟重新计算到期错题。

## 公开构建与GitHub Pages

`python build_learning.py --source public` 只取已核验且再分发许可明确的原项目内容，当前为4道原创样例。
`--source local` 构建用户提供的本地资料版，题库与生成站点均被Git忽略，不会混入公开发布包。
发布前分别完成题目时效、车型适用及权利核查；不要将本地版直接推送公开仓库。
公开学习应用构建输出为 practice-site/，可作为静态站点部署，支持GitHub仓库子路径，所有资源均为相对路径。
本次不部署网页。Pages工作流仅保留在 docs/disabled-workflows/pages.yml.example 作为禁用示例，不在可运行工作流目录中。
