# 驾考脑库 / Jiakao Study Bank v0.1.0

首个公开版本，提供工具代码、中英文说明、离线知识库和静态JSON。网页源码保留供本地使用，不部署网站、不启用GitHub Pages。
First public release: tooling, bilingual guides, offline notes and static JSON. Web source is retained for local use; no website deployment or GitHub Pages.

## 包含 / Included

- 4道原创法规练习，非官方真题、非完整题库。Four original regulatory exercises, not an official or complete exam bank.
- 17种车型目录，未声称收齐各车型题目。A catalog of 17 vehicle codes, without claiming full coverage.
- 本地学习、完整性过滤、错题解析、间隔复习和按时间预算规划的源码。Local learning, completeness filters, explanations, spaced review and time-budget planning source.
- 数据来源、权威性边界、时效性、许可及中英文免责声明。Provenance, authority/freshness limits, licensing and bilingual disclaimers.
